# Yates / Batto — Luxury Naval Architecture & Floating Masterpieces

An ultra-luxurious yacht showcase web experience featuring frame-by-frame canvas scroll scrubbing, Lenis smooth scrolling, editorial typography, and floating glassmorphic interfaces.

## ✨ Features

- **Cinematic Scroll Animation**: High-definition yacht navigation sequence rendered frame-by-frame on canvas tied directly to scroll depth.
- **Lenis Smooth Scroll**: Fluid, weighted scroll dynamics calibrated for a premium luxury experience.
- **Editorial Design System**: Clean white & sky-blue maritime palette with Playfair Display and Plus Jakarta Sans.
- **Floating Glass Navbar**: Frosted glass navigation with smooth section scrolling.

## 🛠️ Tech Stack

- **Vite** — Fast, modern frontend tooling
- **HTML5 & Vanilla CSS** — Luxury editorial design system
- **JavaScript (ES Modules)** — Canvas frame rendering engine & scroll synchronization
- **Lenis** — Modern smooth scroll library

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/am-523/batto.git
cd batto
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
